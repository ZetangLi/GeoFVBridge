# GeoFVBridge 1.1.2

Released: 2026-09-25. Cumulative comparison with the public
[v1.0.1 tag](https://github.com/ZetangLi/GeoFVBridge/tree/v1.0.1)
(`14ecba8`). The release also preserves the public examples, documentation,
packaging, and CI updates on main through `5a8e135`. Those intervening main
commits did not change the application source. There were no separate public
GitHub releases for 1.1.0 or 1.1.1.

## Changes since 1.0.1

| Area | 1.0.1 | 1.1.2 | Implementation and coverage |
|---|---|---|---|
| Input | Gmsh/meshio route | Automatic Gmsh/Petrel dispatch; EGRID with optional INIT, GRDECL, NNC and first UNRST state | `api.py`, `cli.py`, `eclio.py`, `petrel.py`; `test_eclio.py` |
| Source data | Geometry and physical-group semantics | Active/global/IJK identities, MAPAXES, cell properties and source TRAN/NNC audit | `model.py`, `petrel.py`, `validation.py`; synthetic import tests |
| Coarsening | No Petrel vertical-run mode | Optional merging of continuous active K runs per I/J column, preserving membership and aggregating PORV and external TRAN/NNC | `coarsening.py`; volume, PORV and source-connection conservation tests |
| Persistence | HDF5 schema 1.1 | Schema 1.2 stores fields, source identities, members and source connections; reads 1.0/1.1 | `persistence.py`; round-trip and old-schema tests |
| GUI conversion | In-process conversion workflow | Separate cancellable conversion process, JSON progress events and staged output | `worker.py`, `gui/conversion_process.py`, `gui/app.py`; failed-conversion preservation and Unicode protocol tests |
| Boundary selection | Explicit cells/material/Z/top selectors | Canonical material, boundary-group, coordinate, exposed-face and global-plane selection; selected-face preview and cached indexing | `boundary_selection.py`, `gui/pages/page_mesh.py`; all five methods and compatibility tests |
| GUI responsiveness | Earlier preparation/preview/export workflow | Background solver preparation, preview and export, with request-generation checks to reject stale results | `gui/app.py`, `gui/context.py`, `gui/visualizer.py`; GUI workflow tests |
| Diagnostics | Individual non-planar warnings and list-based issue deduplication | Aggregated non-planarity statistics, indexed issue deduplication, cell-field and source-connection checks | `converter.py`, `model.py`, `validation.py`; topology and Petrel tests |
| TOUGH source topology | No Petrel source-connection audit | Disabled geometry is omitted; positive source connections without complete geometric interfaces block export by default | `backends/eco2m.py`; explicit-override and manifest audit tests |
| CONNE direction | Constant `ISOT=1` | Gravity-angle classification: horizontal `ISOT=1`, vertical `ISOT=3` | `ExportConnection.isot`, `_write_mesh`; angle thresholds, reversed ordering, custom/zero gravity and both export paths |

File paths in the implementation column are under `src/geofvbridge/`; tests
are under `tests/`. True geometric centroids, centroid-line `d1/d2`, native
2-D persistence, solver-stage extrusion, stable TOUGH labels, and the seven
GUI stages already existed in 1.0.1 and are retained.

## Compatibility and numerical interpretation

- The package and GUI version is now 1.1.2. Python 3.12 remains required.
- New HDF5 output uses schema 1.2. This release reads 1.0 and 1.1 files;
  older GeoFVBridge releases cannot be assumed to read 1.2 files.
- `inactive_selection` is a single canonical selector. Legacy API/config
  selectors remain supported, but combining them with the canonical selector
  raises an error. Ordinary inactive-cell selection changes existing ELEME
  volumes and does not create cells. Explicit fixed-state backend boundaries
  retain their existing external-cell behavior.
- CONNE belongs to MESH, not INCON. The angle is between the adjacent-cell
  centre line and the gravity vector. Angles 45–135 degrees, including both
  endpoints, use `ISOT=1`; the remaining angles use `ISOT=3`. Zero gravity
  projection selects 1. The cosine comparison includes a `1e-12` tolerance.
- Set ROCKS `PER(1)` to horizontal permeability and `PER(3)` to vertical
  permeability. This classification assumes equal horizontal X/Y permeability.
  Existing isotropic cases with equal components retain the same permeability
  choice numerically; anisotropic cases can change flow results and should be
  revalidated. Distances, connection areas, signed BETAX, labels and ROCKS
  component ordering are retained.
- The GUI's `Vertical axis` is used by geometric boundary/AHTX selection;
  CONNE classification follows the model gravity vector. Align those settings
  with the model's coordinate convention when needed.
- Petrel source TRAN/NNC records are preserved for audit and connectivity.
  They are not a complete transfer of the ECLIPSE flow model or its physics
  into TOUGH. `allow_unrepresented_source_connections=true` deliberately
  omits positive source connections without FV geometry; the manifest counts
  omissions and lists sample IDs. The GUI checkbox defaults to off.
- Vertical-run coarsening is optional and changes model resolution. Conservation
  diagnostics do not establish equality of fine/coarse transient solutions.
- ISOT classification does not implement tensor projection or a correction for
  strongly non-orthogonal meshes. TOUGH2/ECO2M is not distributed with this project.
- Bundled public simulation files are historical examples. They were retained,
  not recomputed by this release, and are not evidence of a new TOUGH solver run.

## 中文：本次累计改进说明

本次对比基准是 GitHub 已发布的 **v1.0.1**，不是本地目录名之间的比较。
主分支之后的公开示例、说明和打包改进也予以保留。中间开发阶段的改动统一
收录到 v1.1.2，不补造 v1.1.0、v1.1.1 的公开发布历史。

1. **新增 Petrel/ECLIPSE 输入。** 从原先 Gmsh 网格入口扩展到 EGRID，支持配套
   INIT、GRDECL、NNC 和首个 UNRST 状态；保留活动单元、I/J/K、属性与源连接信息。
   读取的是模拟器导出文件，不是 Petrel 私有工程数据库。
2. **新增垂向合并。** 可将同一 I/J 柱内连续活动 K 层合并，保留成员映射，汇总
   孔隙体积和外部连接，并提供守恒诊断。该选项改变分辨率，不保证瞬态解不变。
3. **升级数据存储。** HDF5 升为 schema 1.2，新增字段和源连接数据；新版继续
   读取 schema 1.0/1.1。旧版软件不保证能读取新版文件。
4. **改善转换与导出响应。** 大型转换使用独立进程，支持进度和取消，并暂存输出；
   求解器准备、边界预览和 MESH 导出使用后台任务，过滤过期结果。
5. **重做无限体积单元选择。** 支持材料、边界组、坐标、外露面、全局平面五种
   互斥方式，增加索引缓存和选中边界预览。旧配置接口继续兼容，但不得与新选择器混用。
6. **改进可视化和诊断。** 边界预览复用网格数据，保留岩性筛选；非平面面诊断
   改为汇总，验证问题去重，并增加 Petrel 字段和连接检查。
7. **增加 TOUGH 导出完整性检查。** 正传导率源连接若缺少完整 FV 界面，默认阻止
   导出；只有显式接受近似时才忽略这些连接，并在清单记录数量和示例编号。
8. **修正 CONNE 方向。** 由统一 ISOT=1 改为相对重力方向夹角分类：45°–135°
   （含端点）为水平 ISOT=1，其余为垂直 ISOT=3。对应 PER(1) 水平、PER(3) 垂直；
   有符号 BETAX、面积和 d1/d2 不随这项分类改动。水平 X/Y 渗透率应相同。

几何体积质心、交点距离、二维保存后再拉伸、稳定标签及七阶段工作流是此前
已有能力，本次不将其列为新增。普通无限体积选择不创建虚拟单元；后端显式配置
固定状态边界时原有的外部单元能力仍然保留。

各向异性模型重新导出后可能得到不同的求解结果，应重新检查代表性算例。
本次自动测试覆盖转换和文件生成，不等于已完成 TOUGH2/ECO2M 数值求解验收。

## Validation

- Windows / Python 3.12: **64 tests passed, 75 subtests passed, 1 test skipped**.
  The skipped suite requires external reference data supplied through
  `GEOFVBRIDGE_REGRESSION_ROOT`; bundled public input checks passed.
- Ruff static checks passed.
- Wheel and source distribution built with the declared setuptools backend.
- Automated validation covers conversion, geometry, persistence, GUI workflows
  and generated files. A new TOUGH2/ECO2M solver run and a large-model interactive
  GUI acceptance session were not performed for this release.
